# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: we expect everyone interacting with this project (issues, pull requests, Discord, etc.) to act with respect, empathy, and good faith. Harassment, discrimination, and personal attacks are not tolerated.

If you experience or witness behaviour that violates these expectations, please report it through Discord (URL in `gradle.properties` `modDiscord=...`) or by opening a confidential issue.

Maintainers will review every report and respond appropriately, which may include warnings, removal of contributions, or bans from project spaces depending on severity.
